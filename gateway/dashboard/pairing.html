Como conectar

  1. Instale o agente no dispositivo sob uma conta padrão, sem acesso Root/Admin.
  2. Quando a funcionalidade estiver habilitada, execute vpsc-agent pair para solicitar o código.
  3. Compare o código de 10 caracteres e o fingerprint do dispositivo com os exibidos neste painel.
  4. Aprove somente se você reconhece o dispositivo. A conexão começa em modo Padrão.
